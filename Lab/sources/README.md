# Score sources for the repertoire worlds

The compositions are in the public domain. The worlds use only the notes (pitches and rhythms),
read from these MIDI files by `Lab/tools/make_repertoire.py`, which writes
`Sources/AcousticCore/Audio/SatieRepertoireData.swift`. No recording or performance is used.
